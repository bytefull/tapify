# Provisioning

## Scenario

A gym manager wants to set up the device, start enrolling users and keep track of access events.

## Sequence

1. Technician installs device (see install.md)
2. The brand new device is put into provisioning mode, if not user can long press button and wait for led patter/color change
3. Gym manager installs the android app and signup for an account selecting he is an admin and copying the code he received on the device box or scan the qr code, this will prove he can be really the admin of that device
4. Once he complete sign up the app will show a screen telling him he is ready to privision his first tapify device and give him instructions about putting his phone still on top of the device after filling the details such us device name, wifi ssid, wifi password, admin dashboard emaill/username and password
5. Gym manager complete the information and put his phone still on top of the device
6. After few seconds the device will beep in a certain pattern and the led color will be in a certain pattern
7. Phone shows a screen saying that the user should takje his phone off the device and then it shows provisioining was completed successfully
8. Gym manager can now use his phone browser or use his desktop pc to go to the dashboard url (was shown in the app after prov completed) and login
9. Once logged in gym manager can now have access to manually open the gate/turnstile via a button, enroll other users...
10. New gym member comes in so manager deicedes to enroll him
11. New member install app on his phone and sign up and sign in and close the app
12. Gym manager start enrolling member by filling his details into the dashboard
13. Once all details are there dashboard show manager that the user shouild put his phone on the device to enroll him
14. User put his phone and device enroill him and save his poublic key and other data internally
15. Now user can access the gym by tapping
